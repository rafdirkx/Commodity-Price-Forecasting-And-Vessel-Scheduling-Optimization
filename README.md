# **Optimization**
A quantitative econometrics & operations research project combining commodity price forecasting with vessel scheduling optimization.

# Overview
The project studies a commodity transportation problem and develops an optimization-based vessel scheduling approach under operational constraints.

# Components
* Commodity market analysis & price forecasting
* Data preparation and analysis
* Mathematical optimization
* Vessel scheduling
* Evaluation of optimization results

# Tools
Python · Operations Research · Optimization · Data Analysis

# Project Structure
Data/ contains project data
Results/ contains generated results
vessel_scheduling.py contains the main scheduling implementation
The project report provides the full methodology and analysis
